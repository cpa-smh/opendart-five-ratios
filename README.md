# OpenDART 재무비율 분석

기업명과 사업연도를 입력하면 최근 3년의 영업이익률, ROE, 매출채권회전율, 부채비율, 이자보상배율을 계산합니다. 매출채권 손실충당금과 대손·기대신용손실(ECL)은 별도로 정리합니다. 결과는 Excel과 PNG로 저장합니다.

Python 3.12 / Windows 기준입니다. 실제 조회에는 OpenDART 인증키가 필요하고, `--demo`는 키 없이 가상 데이터로 실행합니다.

## 설치 및 실행

PowerShell에서 이 폴더를 연 뒤 실행합니다. 가상환경 활성화 없이도 아래 명령을 사용할 수 있습니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

메모장에서 `.env`의 등호 오른쪽을 발급받은 40자리 키로 바꿉니다.

```dotenv
OPENDART_API_KEY=발급받은_40자리_키
```

실제 조회:

```powershell
.\.venv\Scripts\python.exe main.py --company "삼성전자" --end-year 2025
```

입력을 물어보는 방식:

```powershell
.\.venv\Scripts\python.exe main.py
```

같은 이름의 기업이 여러 개라면 후보의 종목코드 또는 DART 고유번호를 입력합니다. 미리 지정할 수도 있습니다.

```powershell
.\.venv\Scripts\python.exe main.py --company "삼성전자" --identifier 005930 --end-year 2025
```

데모와 테스트:

```powershell
.\.venv\Scripts\python.exe main.py --demo
.\.venv\Scripts\python.exe -m pytest -q
```

결과는 `reports/run_날짜_시간/`에 생성됩니다. `financial_analysis.xlsx`, `analysis.json`, `raw_snapshot.json`, `charts/`를 확인하세요. 출력 위치는 `--output-dir`로 지정하며 기존 파일 보호를 위해 빈 폴더만 받습니다. Excel을 열어 놓은 채 같은 파일을 덮어쓰지 않습니다.

## 계산하는 지표

| 지표 | 계산식 | 확인하는 내용 |
|---|---|---|
| 영업이익률 | 영업이익 / 매출액 | 매출 대비 영업이익 |
| ROE | 순이익 / 평균 자본 | 자기자본 수익성 |
| 매출채권회전율 | 매출액 / 평균 매출채권 순액 | 판매대금 회전 속도 |
| 부채비율 | 기말 부채 / 기말 자본 | 자본 대비 부채 규모 |
| 이자보상배율 | 영업이익 / 손익 이자비용 | 이자비용을 감당하는 정도 |

평균은 `(기초+기말)/2`입니다. 표시 대상 3개년과 직전 연도를 합쳐 4개년을 조회합니다. 내부 비율은 0.15처럼 저장하고 Excel·화면에서 15%로 표시합니다. 회전율과 이자보상배율은 배 단위입니다.

연결 ROE는 당기 지배주주 순이익, 기초·기말 지배주주 자본이 모두 있을 때 지배기업 소유주 기준을 사용합니다. 하나라도 없으면 전체 순이익과 전체 자본으로 함께 전환합니다. 선택한 범위는 계산 시트에 표시합니다.

매출채권은 기타채권·미수금·계약자산을 제외한 유동+비유동 전체 순액을 사용합니다. 전체 매출액을 외상매출액 대신 쓰므로 실제 회수 속도를 완전히 설명하는 지표는 아닙니다. 제각, 채권 양도, 환율 변동도 영향을 줄 수 있습니다.

이자비용은 손익에 인식한 금액입니다. 금융비용 합계, 현금흐름표의 이자 지급액, 리스 이자만으로 대체하지 않습니다. 분모가 0 이하이거나 필수 금액이 없으면 결과를 비우고 사유를 남깁니다. 영업손실과 대손 환입은 부호를 유지합니다.

## 데이터와 검증

- 현재 기업개황상 유가·코스닥·코넥스 상장기업이며 업종코드 64~66이 아닌 기업을 대상으로 합니다. 과거 시점의 상장 상태를 복원하는 도구는 아닙니다.
- CFS를 기본으로 조회합니다. 연결 자료가 없는 연도가 있으면 **4개년 전체를 OFS로 다시 조회할지** 묻습니다. `--allow-ofs`는 이 전환에 미리 동의하는 옵션입니다. 연도별로 연결·별도를 섞지 않습니다.
- 기업개황 결산월과 같은 공시의 실제 결산일·정상 12개월 손익기간, KRW 표시를 확인합니다. 결산월 변경·단기 사업연도는 비교 대상에서 제외합니다.
- 표준 계정 ID, 정확한 계정명 순서로 찾습니다. 후보가 충돌하면 합산하거나 첫 행을 선택하지 않습니다. IS를 우선하고 CIS 후보도 기록합니다.
- 자산=부채+자본과 매출-매출원가=매출총이익을 대사합니다. 해당 계정이 없으면 검증도 SKIP입니다.
- 조회 시점에 API가 반환하는 각 사업연도 **당기 금액**을 사용합니다. 나중 연도의 비교표시 금액으로 과거 수치를 소급 교체하지 않습니다. 재작성/정정으로 인한 차이가 있을 수 있으므로 접수번호와 조회시간을 보존합니다.
- `--snapshot`은 저장된 원본을 그대로 재분석합니다. 다시 실시간 조회하면 정정공시 등으로 결과가 바뀔 수 있습니다.
- API 인증·한도 오류, 자료 없음, HTTP·네트워크 오류를 구분합니다. 통신 오류·서버 혼잡만 최대 3회 시도하고 인증 오류는 재시도하지 않습니다. 특정 연도 자료가 없더라도 나머지 연도 보고서를 생성합니다.

## 주석 확인과 보완 입력

**기업명만으로 모든 기업의 5개 지표와 ECL이 항상 완성되는 것은 아닙니다.** 전체 재무제표 API에 이자비용이나 전체 매출채권이 없는 기업은 주석 보완이 필요합니다.

프로그램은 기본적으로 해당 접수번호의 연결/별도 감사보고서 XML과 열람용 TXT를 `documents/`에 저장합니다. `--skip-documents`로 생략할 수 있습니다. 문서 형식이 맞지 않거나 해당 감사보고서가 없으면 상태를 기록하고 계속 진행합니다. 임의의 표를 자동 추정해서 회계 금액으로 사용하는 기능은 없습니다.

1. `examples/supplement.example.json`을 프로젝트 루트의 `supplement.local.json`으로 복사합니다.
2. 해당 사업연도와 동일 접수번호의 주석을 확인합니다. 기초 잔액을 위해 4개년 레코드를 작성합니다.
3. 금액은 **원 단위 문자열**, 확인되지 않은 값은 `null`로 입력합니다. 백만원 표는 1,000,000을 곱합니다. 0과 미확인을 구분합니다.
4. `source_url`에 해당 공시 링크, `source_ref`에 주석·표·페이지, 원래 단위와 범위 확인 근거를 기록합니다.
5. 저장된 스냅샷에 보완 입력을 붙여 재실행합니다.

```powershell
.\.venv\Scripts\python.exe main.py --snapshot "reports\이전실행폴더\raw_snapshot.json" --supplement supplement.local.json
```

| 필드 | 입력 내용 |
|---|---|
| corp_code, year, fs_div | 기업·사업연도·CFS/OFS. 선택한 API 자료와 일치해야 함 |
| balance_date, rcept_no | 실제 결산일과 접수번호 |
| currency, unit | 모두 KRW. 숫자는 원으로 환산 |
| origin | 사람이 주석을 확인해 입력하면 manual. document는 검증한 별도 추출 도구의 입력용 |
| scope | total_trade: 전체 매출채권. current_trade는 본 프로그램의 전체 범위 회전율에 사용하지 않음 |
| reported_basis | API가 전체 순액이면 net, 총액이면 gross. API에 같은 전체 범위 계정이 없으면 not_available |
| gross, allowance, net | 매출채권 총액·양수 충당금·순액. 총액-충당금과 순액을 대사 |
| current_net | API가 유동 매출채권이면 주석의 유동 순액을 입력해 추가 대사. 전체 순액과 구분 |
| ecl_expense | 매출채권에 한정한 당기 대손상각비/순 ECL 비용. 환입은 음수 |
| writeoffs, other_movements | 제각은 양수, 기타 순변동은 증가 양수/감소 음수 |
| recoveries | 참고용 회수액. 롤포워드에 자동 가산하지 않음 |
| interest_expense, interest_scope | 손익 이자비용(0 이상), profit_loss |

총액·충당금이 없더라도 API가 전체 순액임을 확인한 `net` 주석은 순액 회전율에 사용할 수 있습니다. 출처가 없거나 범위·공시·금액이 충돌하면 제외합니다. 총액과 충당금이 없으면 설정률은 계산하지 않습니다.

대손상각비와 ECL은 같은 손실을 설명하는 경우 중복 비용으로 더하지 않습니다. 기말 충당금과 당기 비용도 구분합니다. `기초 충당금+당기 비용-제각+기타=기말 충당금`은 필요한 항목이 모두 있을 때만 검증합니다. 회수는 기업의 실제 회계처리에 맞춰 기타에 반영 여부를 판단하고 출처에 적으세요.

`examples/samsung_2022_2025.reviewed.json`은 실제 삼성전자 연결감사보고서 주석 7과 24를 확인해 보완한 자료입니다. 자동 추출 결과가 아니며, 예시 접수번호와 현재 조회 접수번호가 다르면 사용되지 않습니다. 다음처럼 실제 조회에도 함께 사용할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe main.py --company "삼성전자" --end-year 2025 --supplement examples/samsung_2022_2025.reviewed.json
```

## Excel 구성

| 시트 | 내용 |
|---|---|
| 분석요약 | 최근 3개년 Python 계산 결과와 지표의 의미 |
| 원본재무데이터 | 수집한 모든 행과 원래 필드를 열별로 보존, 기업·연도·공시 링크 |
| 계정매핑 | 선택한 금액, 계정 ID·이름, 후보, 상태, 근거 |
| 재무비율계산 | 분자·기초/기말 분모, Python 값, Excel 수식, 둘의 차이 |
| 매출채권_ECL | 총액·충당금·순액·비용·제각·기타, 보조 비율, 출처 |
| 검증결과 | 기간·합계·충당금 대사, 누락·충돌 사유 |
| 그래프 | 계산 셀에 연결된 Excel 추세 차트 5개 |

Excel 금액은 원 단위입니다. openpyxl은 Excel 수식을 실행하지 않으므로 Excel에서 파일을 열 때 재계산하도록 설정합니다. 일부 미리보기 도구에서는 수식·차트가 비어 보일 수 있습니다. Python 결과와 PNG는 Excel 없이도 확인 가능합니다. 숫자는 Excel의 약 15자리 정밀도 한계를 받으므로 원본 JSON과 Decimal 계산이 기준입니다.

엑셀 수식은 사용한 금액의 링크와 산식을 확인하기 위한 것입니다. 원본·주석 입력을 고쳤다면 Python을 재실행하여 검증 상태·계산 허용 조건·요약·PNG도 함께 갱신하세요. 결측은 차트에서 0으로 대체하지 않습니다.

## 코드 읽는 순서

| 파일 | 역할과 주요 흐름 |
|---|---|
| main.py | 입력을 읽고 수집→분석→Excel→PNG 함수를 차례로 호출 |
| dart_client.py | API 요청, 타임아웃·재시도, 기업 목록과 재무제표 응답 확인 |
| documents.py | 해당 연결/별도 공시 원문 다운로드. 표 해석은 보완 입력으로 구분 |
| account_mapper.py | 원본 행에서 계산에 필요한 계정 하나를 선택. Decimal로 금액 변환 |
| validation.py | 기업 업종·상장 구분과 실제 재무제표 기간·통화 확인 |
| credit_risk.py | 매출채권 주석을 읽고 순액·충당금·ECL 대사 |
| ratios.py | 분자와 분모를 받아 5개 비율 계산. 나눌 수 없는 이유도 반환 |
| pipeline.py | 4개년 자료를 모으고 계정·주석을 연결. 스냅샷 저장·재실행 |
| excel_report.py | openpyxl로 7개 시트, 계산식, 차트 작성 |
| charts.py | matplotlib으로 결측을 제외한 PNG 그래프 작성 |
| sample_data.py | 실제 기업과 무관한 가상 4개년 자료 생성 |
| tests/test_analysis.py | 계산·범위·API 오류·Excel 저장 회귀 테스트 |

예를 들어 매출채권회전율은 `main.py`가 읽은 주석을 `pipeline.py`에서 API 공시와 연결하고, `credit_risk.py`가 총액-충당금=순액인지 확인한 뒤 `ratios.py`가 기초·기말 평균으로 나눕니다. 결과와 검증 사유가 함께 `excel_report.py`로 전달됩니다.

## 한계와 보안

주석 형식은 기업마다 다르므로 보완 입력이 필요할 수 있습니다. 이 도구는 감사의견이나 손실충당금의 적정성을 판단하지 않습니다. 설정률이 높아졌다는 이유만으로 회수가 나빠졌다고 단정하지 마세요. 고객 구성·보험·담보·연체·전망정보를 추가로 확인해야 합니다.

`.env`, `reports/`, 개인 보완 입력은 GitHub에서 제외합니다. 압축·업로드 전에도 실제 키가 포함되지 않았는지 확인하세요. 오류 응답 원문과 인증키가 들어간 URL은 출력하지 않습니다. 기존 환경변수에 같은 이름의 키가 있으면 `.env`보다 우선합니다.
